# Future Interns Portfolio

A personal portfolio website built with React and Vite to showcase my profile, skills, projects, and contact information.

🚀 About the Project

This project is part of my frontend development journey. It provides a place to present my background, technical skills, and projects in a professional and accessible way.

✨ Features

- Personal introduction and profile
- Technical skills showcase
- Project portfolio
- Contact section
- Responsive user interface
- Links to professional profiles

🛠️ Technologies Used

- **React** — building the user interface
- **Vite** — frontend development server and build tool
- **JavaScript** — application logic
- **HTML5** — page structure
- **CSS3** — styling and layout
- **Git and GitHub** — version control and source code hosting

📦 Getting Started

Follow these steps to run the project on your local machine.

#Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

Installation

1. Clone the repository:

   git clone https://github.com/lwam24/FUTURE_FS_01.git

2. Navigate to the project directory:

   cd FUTURE_FS_01

3. Install the dependencies:

   npm install

4. Start the development server:

   npm run dev

5. Open the local URL displayed in your terminal, usually `http://localhost:5173`.
